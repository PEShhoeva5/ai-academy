Шаг 2. Разбор текстовых программ (LLM Studio)

🤖 Программа ChatGPT (Модель GPT-4o)

Лучший универсальный ассистент для быстрой генерации идей, постов, писем, коммерческих предложений. При включении тумблера Web Search модель мгновенно сканирует интернет и выдает выжимку свежих новостей за сегодняшний день.

Пример готового промта:
"Действуй как ИТ-копирайтер. Напиши email-рассылку для клиентов нашей компании об обновлении личного кабинета. Перечисли 3 главные выгоды. Тон дружелюбный."

🧠 Программа Claude (Модель Claude 3.5 Sonnet)

Лидер в области сложной лингвистики. Пишет тексты «человеческим языком» без роботизированных штампов. Превосходно анализирует огромные юридические договоры, финансовые отчеты и пишет сложный программный код без ошибок.

Пример готового промта:
"Действуй как юрист. Проанализируй этот текст договора на оказание услуг [Вставить текст]. Найди 3 скрытых юридических риска для исполнителя."

🔬 Программа DeepSeek R1 (Рассуждающая модель)

ИИ нового поколения. Перед выводом ответа она запускает внутренний цикл пошаговых логических проверок и мыслей, исключая ошибки. Незаменима для тяжелой математики и программирования.

Пример готового промта:
"Действуй как старший Python-разработчик. Проанализируй этот кусок кода и лог ошибки сервера. Пошагово разбери, почему падает сервер, и выдай исправленный вариант."
